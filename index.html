Настройка Облачного Сервера (Firebase)

По умолчанию система использует локальное хранилище браузера. Укажите конфигурацию Firebase для синхронизации в реальном времени. Можно вставлять весь JS-код с `const firebaseConfig = ...`.

Внимание! В консоли Firebase необходимо включить:
1. Authentication: Вкладка Sign-in method → активируйте Анонимный (Anonymous) вход.
2. Firestore Database: Создайте базу данных и проверьте вкладку Rules (Правила).
