Настройка Облачного Сервера (Firebase)

По умолчанию система использует подключение к Firebase Firestore для синхронизации отчетов в реальном времени.

Требования Firebase:
1. Authentication: Включите Anonymous (Анонимный) вход.
2. Firestore Database: Создайте базу данных в режиме тестирования.
